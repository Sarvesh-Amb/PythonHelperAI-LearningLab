Sample tutor response

Exercise: Write a function that adds two numbers.
“Try thinking about what a function needs: a name, some input, and a result. Ask yourself: what should happen to the numbers before you return them? Start with a tiny version and test it.”

What this project does

1

Learn by chapter

Students progress through beginner Python and DSA concepts with guided exercises instead of full solution dumps.

2

Local Gemma support

The local workflow uses Ollama and Gemma models so the assistant can run from a personal machine without needing cloud APIs.

3

Friendly hints

The tutor stays encouraging and beginner-focused, asking one guiding question at a time instead of giving away answers.

How the local flow works

ollama pull gemma3:1b
python app.py
# choose provider: local
# choose model: gemma3:1b
# click "Get hint"
